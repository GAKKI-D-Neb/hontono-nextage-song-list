# 本当のNEXTAGE祭2026 曲紹介リスト 非公式Viewer

「本当のNEXTAGE祭2026」の公開されている曲紹介リストを、検索や絞り込みをしながら見やすく閲覧するための非公式Viewerです。

公開されているGoogleスプレッドシートの情報を読み込み、ブラウザ上で整理して表示します。

> [!NOTE]
> このViewerは「本当のNEXTAGE祭2026」の公式ツールではありません。  
> 個人が非公式に作成したものです。

## 主な機能

- 曲名・投稿者名による検索
- 使用ボカロによる絞り込み
- ニコニコ動画の埋め込み表示
- 作品ページ・投稿者Xアカウントへのリンク
- 作品紹介文の省略表示・展開
- 作品のランダム並び替え
- スプレッドシート上の元の順番への復帰
- PC・スマートフォン対応

## ファイル構成

```text
.
├── README.md
└── hontono-nextage-2026
    └── index.html
```

Viewer本体は以下のファイルです。

```text
hontono-nextage-2026/index.html
```

## 使い方

特別なインストールやビルドは必要ありません。

### 1. リポジトリをダウンロードする

GitHubのリポジトリページから、

**Code → Download ZIP**

を選択してダウンロードします。

ダウンロードしたZIPファイルを展開してください。

Gitを使用する場合は、リポジトリをcloneしても構いません。

### 2. `index.html` を開く

展開したディレクトリ内の、

```text
hontono-nextage-2026/index.html
```

をダブルクリックするなどして、Webブラウザで開きます。

基本的にはこれだけで使用できます。

なお、Googleスプレッドシートのデータやニコニコ動画の埋め込み情報をインターネット経由で取得するため、利用にはインターネット接続が必要です。

## 直接開いても表示されない場合

ブラウザの設定などにより、ローカルの `index.html` から外部データを正常に読み込めない場合があります。

その場合は、簡単なローカルWebサーバーを起動して使用してください。

Pythonがインストールされている場合、リポジトリのルートディレクトリで以下を実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/hontono-nextage-2026/
```

ローカルWebサーバーを終了する場合は、ターミナルで `Ctrl + C` を押してください。

## Viewerの操作

### 曲名・投稿者名を検索

ページ上部の検索欄に文字を入力すると、曲名または投稿者名に一致する作品だけを表示します。

### 使用ボカロで絞り込み

「すべてのボカロ」と表示されているプルダウンからボカロを選択すると、そのボカロを使用している作品だけを表示します。

曲名・投稿者名による検索と、使用ボカロによる絞り込みは同時に使用できます。

### ランダム

「↻ ランダム」を押すと、作品の表示順をランダムに並び替えます。

もう一度押すと、再度ランダムに並び替えます。

検索や使用ボカロによる絞り込みを行っている場合も、その条件を維持したままランダム表示できます。

### 元の順番に戻す

ランダム表示後に「元の順番に戻す」を押すと、Googleスプレッドシート上の元の並び順に戻ります。

検索や使用ボカロによる絞り込み条件は維持されます。

### 作品紹介文

作品紹介文が長い場合は、一部のみ表示されます。

「続きを読む」を押すと全文を表示し、「閉じる」を押すと元の表示に戻ります。

### 作品を見る

「作品を見る」を押すと、ニコニコ動画の作品ページを新しいタブで開きます。

### X

「X」を押すと、その作品の投稿者のXアカウントを新しいタブで開きます。

## データについて

作品情報は、公開されている「本当のNEXTAGE祭2026」のGoogleスプレッドシートから取得しています。

Viewer側ではスプレッドシートの内容を読み取って表示しているだけで、スプレッドシートへの書き込みや変更は行いません。

そのため、元のスプレッドシートが更新された場合は、Viewerを再読み込みすると基本的に最新の内容が反映されます。

## 技術構成

複雑なシステムは使用せず、基本的に1つのHTMLファイルだけで動作します。

- HTML
- CSS
- JavaScript
- OpenSheet
- ニコニコ動画 埋め込みプレイヤー

バックエンドやデータベースは使用していません。
